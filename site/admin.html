Đăng nhập bằng GitHub

Trang quản trị ghi thay đổi trực tiếp vào repo GitHub rồi tự động triển khai lại website. Bạn cần một Personal Access Token có quyền repo.

Cách tạo token (30 giây)
  1. Vào github.com/settings/tokens
  2. Generate new token (classic)
  3. Expiration: chọn thời hạn bạn muốn
  4. Tick mục repo (toàn bộ)
  5. Generate token → copy dán vào ô trên

Token chỉ lưu trong trình duyệt của máy bạn (localStorage), không gửi đi nơi khác.

Hướng dẫn sử dụng

Mọi thao tác lưu vào GitHub, trang web tự dựng lại trong ~1 phút

1. Đăng nhập

  • Tạo token 1 lần: github.com/settings/tokens/new
  • Đặt Expiration (hạn), tick mục repo → Generate token
  • Dán token vào ô → bấm Đăng nhập. Trang sẽ nhớ token, lần sau mở là vào thẳng.
  • Đổi/xoá token: Settings → Developer settings → Tokens

2. Danh mục

  • ＋ Tạo danh mục: gõ tên → Enter.
  • ↑ ↓: đổi thứ tự hiển thị ở menu trang chủ.
  • Đổi tên: tên mới sẽ tự áp dụng cho mọi sách đang ở trong đó.
  • Xóa danh mục đang có sách: chọn danh mục đích để chuyển hết sách sang, rồi mới xóa.

3. Thêm / sửa / xóa sách

  • ＋ Thêm sách (tab Sách): nhập tên, tác giả, danh mục, số trang; có file PDF thì điền đường dẫn.
  • Sửa: đổi tên, tác giả, danh mục (đây là cách chuyển 1 cuốn sang danh mục khác), số trang.
  • Xóa: bỏ 1 cuốn; tick vào ô nếu muốn xóa luôn file PDF kèm theo.
  • Chuyển nhiều cuốn: tick các ô bên trái → chọn danh mục ở thanh Chuyển vào.

4. Tải sách PDF (nhiều file 1 lúc)

  • Chọn "Danh mục cho lần tải này" trước — mọi file thả vào sẽ vào danh mục đó.
  • Thả nhiều file PDF cùng lúc (mỗi file ≤ 100MB).
  • Sửa nhanh tên sách / tác giả / số trang ngay trong bảng (mỗi dòng 1 cuốn).
  • Bấm ⬆ Tải lên — xong. File nằm ở /pdfs/, sách hiện ở trang chủ.
  • Cần file riêng 1 danh mục khác: sửa ô danh mục của dòng đó trước khi bấm Tải lên.

5. Đổi giao diện

  • Tab 🎨 Giao diện: sửa tên thư viện, tiêu đề, mô tả, màu chủ đạo.
  • Bấm Xem trước thấy ngay, rồi 💾 Lưu giao diện.
  • Không cần biết code — toàn bộ lưu vào file data/settings.json.

6. Khi có lỗi

  • Lỗi 401: token sai/hết hạn → tạo token mới (bước 1).
  • Lỗi 404: token thiếu quyền → tạo lại token classic và tick repo.
  • "Có người khác vừa commit": bấm thử lại sau vài giây.
  • Hết hạn mức API: chờ khoảng 1 giờ rồi làm tiếp.
  • Sửa nhầm? Vào lịch sử commit để xem, hoặc báo mình hoàn tác.

Bảo mật: token giống như mật khẩu — ai có token thì ghi được vào web của bạn. Dùng máy chung nhớ bấm Đăng xuất khi xong. Không gửi token cho ai.
