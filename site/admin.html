Đăng nhập bằng GitHub

Trang quản trị ghi thay đổi trực tiếp vào repo GitHub rồi tự động triển khai lại website. Bạn cần một Personal Access Token có quyền repo.

Cách tạo token (30 giây)
  1. Vào github.com/settings/tokens
  2. Generate new token (classic)
  3. Expiration: chọn thời hạn bạn muốn
  4. Tick mục repo (toàn bộ)
  5. Generate token → copy dán vào ô trên

Token chỉ lưu trong trình duyệt của máy bạn (localStorage), không gửi đi nơi khác.
